# Credentials are intentionally NOT stored in this file.

Live credentials live only in the server `.env` (ADMIN_EMAIL / ADMIN_PASSWORD),
which is git-ignored, or are set interactively via:

    php artisan admin:set-credentials

Local development fixtures are created by the seeders, which read the same
env keys and fall back to these non-production values:

    php artisan db:seed

  Admin:  admin@optyamazone.com / password
  Buyer:  buyer@test.com       / password
  Seller: seller@test.com      / password
